### LLM key（队友：DashScope qwen-max）

1. 登录 [阿里云百炼 DashScope](https://dashscope.aliyun.com) 注册账号 → API-KEY 管理 → 创建 key。
2. 写进自己机器 `.env`（gitignored）：`DASHSCOPE_API_KEY=<你的 key>`。
3. **查额度**：控制台「用量/额度」确认免费额度够跑 **约 150 万 token**（四人分片后每人
   约需 150 万）。不够就小额充值（qwen-max 约 input ¥0.02/千 + output ¥0.06/千，
   150 万 token ≈ ¥30–60），**跑前先确认，避免跑到一半额度耗尽白跑**。

的 `generation` 段；`api_key_env` 改为对应环境变量名，key 写进 `.env`。若该端点
走不了 OpenAI 兼容协议，则退回 DashScope qwen-max（与队友同口径）。

## 五、跑批命令（照抄，只改区间）

```bash
python -m eval.runner \
  --cases <数据仓>/审计公告/案例标注表.csv \
  --registry eval/registry-export.json \
  --pipeline real --ablate-all \
  --offset <你的 offset> --limit <你的 limit> \
  --out runs/<你的名字>
```

`eval/registry-export.json` 已随仓库提供（条款级文号注册表，供引用错误率核验），
**四人必须用同一份**，合并时才能对账。
