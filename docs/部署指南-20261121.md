## 0.5 购买参数速查（逐项照买，避免备案返工）

**实名一致性红线（最重要）**：云账号实名 ＝ 域名实名 ＝ ICP 备案主体 ＝
将来小程序主体 ＝ **kohl 本人身份证**（路线图 D4）。任何一环用了别人的
身份，备案会卡到重来。

| 项 | 参数 | 说明 |
|---|---|---|
| 账号 | 腾讯云注册＋个人实名认证（微信扫码/人脸） | 用 kohl 本人身份 |
| 服务器 | 轻量应用服务器 → 地域 **广州**（境内！离得近）→ 镜像 **Ubuntu Server 22.04 LTS** → 套餐 **4C4G** → 时长 **1 年（包年包月）** | 新客 109/年；**境内＋包年包月＋剩余 ≥3 个月**是个人备案使用服务器的条件；支持升配则更稳 |
| 域名 | `.cn`，短、好念、无敏感词（如 yueceshao.cn 一类） | 注册人实名＝本人；首年促销价约 10–30 元 |
| 防火墙 | 轻量控制台确认放行 22/80/443 | 80/443 是后续 nginx/HTTPS 用 |

**不买清单**：境外节点（香港等——**不能备案**）；按量计费（不能备案）；
1C1G（模型跑不动）；有效期不足 3 个月的短时长（备案用不了）。

## 2 服务器五样前置机械核验（分发文档 §三同款，逐条执行）

## 3 安装与 systemd 落位

```bash
cd /opt/yueceshao/yueceshao
python3 -m venv /opt/yueceshao/venv
# 第一步：基础依赖（requirements.txt 末两行 ML 依赖默认注释——CI 保持轻量的取舍）
/opt/yueceshao/venv/bin/pip install -r requirements.txt
# 第二步：⚠ 必须启用 ML 依赖再装一次——真实管线装配（embedding＋重排）起动即
# 触发 sentence-transformers/FlagEmbedding 导入，不装则服务必然 ImportError 拒启
sed -i '' 's/^# sentence-transformers/sentence-transformers/; s/^# FlagEmbedding/FlagEmbedding/' requirements.txt
/opt/yueceshao/venv/bin/pip install -r requirements.txt
# （macOS 用 sed -i ''；Linux 用 sed -i；或手动删掉这两行行首的「# 」）
sudo cp deploy/yueceshao-api.service /etc/systemd/system/
sudo mkdir -p /etc/yueceshao && sudo vim /etc/yueceshao/yueceshao.env   # 0600，写 key
sudo systemctl daemon-reload && sudo systemctl enable --now yueceshao-api
journalctl -u yueceshao-api -f          # 看冷启动
curl -s http://127.0.0.1:8000/health    # 期待 real-retrieval-qwen-llm + index_chunks=20099
```

**两条硬约束（unit 文件头有注释，复述于此）**：

1. **`--workers 1`**：任务表在进程内——多进程各自持有任务表，轮询 404。
   扩容前先把任务表外置（Redis），那是架构升级不是改数字。
2. **`--proxy-headers --forwarded-allow-from 127.0.0.1`**：nginx 反代下让
   `client.host` 反映真实客户端 IP（限流按 IP 计数的正确性依赖它）。

### 3.1 swap（2G 内存机器必须；4G 机器可选但建议）

```bash
sudo fallocate -l 4G /swapfile && sudo chmod 600 /swapfile \
  && sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab   # 重启持久
free -h   # 确认 Swap 行生效
```

## 4 域名备案（购买后立即启动——全计划关键路径）

1. **前置**：域名实名认证通过（注册后立即在域名控制台提交，1–3 天）；
   服务器满足境内＋包年包月＋剩余 ≥3 个月（§0.5 参数即满足）。
2. **个人备案无需授权码**：备案授权码是企业主体才需要的；个人备案在
   腾讯云控制台「网站备案」里**直接选择这台轻量服务器作为备案资源**。
3. 材料：本人身份证＋人脸核验＋常用手机号（管局短信核验用，寒假保持畅通）。
4. **网站名称避开时政/政务敏感词**（「政策」「政务」「咨询」易被驳回）——
   用工具口径，如「粤策哨自查助手」；网站内容备注按「申报前自查辅助工具」
   描述，与调研 §1 类目对策同口径（红线③延伸）。
5. 流程与周期：腾讯云初审（1–2 天）→ 工信部短信核验 → 管局审核
   （最长 20 个工作日）→ 通过短信。
6. **备案期间域名不得解析开站**——等待期正好做 §1–§3 的服务器落位
   （SSH/内网传索引落模型不受限），域名一过审就 certbot＋nginx 上线。

## 7 日常运维

- 日志：`journalctl -u yueceshao-api -f`（含限流拒绝/任务失败/清理日志）
- 重启：`systemctl restart yueceshao-api`——**任务表清零**（R2 取舍），
  轮询中的任务变 404，客户端重新提交；限流桶清零
- 更新：`git pull`（main）→ `pip install -r requirements.txt`（有变更时）
  → `systemctl restart`——重启前跑 §2 的 1/2 两条核验
- 姿态与免责/AI 标识：全部服务端注入（红线③执行点在 API worker），nginx
  只透传，**任何前端不得渲染未带标识的裸报告**

## 8 红线对照（部署场景）

1. 语料/索引/模型**不经 git**（§1 通道表）；服务器上的语料与 dev 同源 rsync；
2. key 只在 `/etc/yueceshao/yueceshao.env`（0600，仓库外）——unit 文件、
   config.json、小程序包都不是它的家；
3. 数据仓服务器只读（`git clone` 后**禁 push**，§8.6 通道 B 不变）；
4. 审计公告不进索引：verify_index 全绿（审计公告零泄漏）才允许上线；
5. AI 生成标识＋免责声明由服务端注入（红线级，2025-09 法规），部署不改变
   其执行点。
